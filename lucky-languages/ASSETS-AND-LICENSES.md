# Third-party 3D teacher avatars

Lucky Languages Academy's optional 3D teacher gallery references the VALID (Validated Avatar Library for Inclusion and Diversity) avatars, converted to glTF by the c-frame/valid-avatars-glb project. Models and preview thumbnails are loaded from a pinned jsDelivr URL at runtime; the binary assets are not copied into this repository.

- Avatar conversion repository: https://github.com/c-frame/valid-avatars-glb
- Original VALID project: https://github.com/google/valid-avatar-library
- Paper: Do, T. D., Zelenty, S., Gonzalez-Franco, M., & McMahan, R. P. (2023), “VALID: a perceptually validated Virtual Avatar Library for Inclusion and Diversity,” Frontiers in Virtual Reality 4:1248915. https://doi.org/10.3389/frvir.2023.1248915
- Original VALID models are released under Creative Commons Attribution 4.0 International; credit the authors and cite the paper when using them.
- The c-frame conversion repository includes an MIT license for its conversion code.

The models are rigged, textured 3D avatars. They are not photogrammetry scans and should not be described as photorealistic human scans. Network access is required to load the gallery. Users can alternatively preview their own GLB model locally in the browser.
